brightness · saturate · hueRotate

비용 거의 없음ColorFiltered 색 행렬

밝기·채도·색상을 바꿉니다. tint 와 함께 ColorFiltered 하나에 색 행렬로 합쳐지므로 레이어가 늘지 않습니다. 계산식이 CSS filter 와 같아서 웹 미리보기와 단말 결과가 같습니다.

JSON

{ "prop": "saturate", "keys": [
  { "t": 0, "v": 1 },
  { "t": 1200, "v": 0, "curve": "easeInOut" }
]}

참고

tint 와 함께 쓰면 행렬 하나로 곱해 합칩니다. reduced 품질에서도 유지합니다. 기본값은 brightness 1, saturate 1, hueRotate 0 입니다.

translateXRel · translateYRel

비용 낮음FractionalTranslation

이동 거리를 px 이 아니라 요소 크기의 비율로 줍니다. px 이동은 거리가 고정이라 요소 너비가 다르면 느낌이 달라집니다. 아래 두 화면은 너비가 다른 막대 3개가 점선 창 왼쪽에서 들어오는 장면입니다.

JSON

{ "prop": "translateXRel", "keys": [
  { "t": 0, "v": -1 },
  { "t": 700, "v": 0, "curve": "easeOutCubic" }
]}

참고

px 이동과 함께 쓰면 더해집니다.

clipCircle

비용 중간ClipOval (원)

원이 커지며 요소가 드러납니다. 1 이면 요소 전체가 보입니다. 원의 중심은 타임라인의 origin 을 따릅니다. 사각 clip 보다 비싸지만 blur·shimmer 보다는 쌉니다.

JSON

{ "v": 1, "durationMs": 3800, "origin": "center",
  "tracks": [{ "prop": "clipCircle", "keys": [
    { "t": 0, "v": 0 },
    { "t": 700, "v": 1, "curve": "easeOutCubic" },
    { "t": 2600, "v": 1 },
    { "t": 3200, "v": 0, "curve": "easeInCubic" }
  ]}]}

참고

값 1 은 origin 에서 가장 먼 꼭짓점까지 덮는 반지름입니다. 그래서 origin 이 모서리여도 1 에서 정확히 전체가 보입니다. 사각 clip 과 함께 쓰면 둘 다 적용됩니다.

값 채널 (Motion.builder)

비용은 child 가 정함Motion.builder

그리는 속성이 아니라, 타임라인이 계산한 숫자를 child 에 넘깁니다. 가격이 바뀌는 연출이나 진행 막대처럼 내용 자체가 움직이는 경우에 씁니다.

Dart

Motion.builder(
  timeline: tl,           // "channels": [{ "name": "price", ... }]
  controller: clock,
  builder: (context, v) => Text(won(v['price'] ?? 0)),
)

참고

값이 바뀔 때마다 builder 가 다시 불리므로, 일반 속성과 달리 child 가 매 프레임 빌드됩니다. 숫자 텍스트처럼 작은 위젯에만 씁니다.

feather

비용 높음ShaderMask 그라데이션

clip 와이프의 경계를 그라데이션으로 흐립니다. shimmer 와 같은 셰이더 마스크라 비쌉니다. reduced 품질에서는 생략되어 일반 clip 와이프로 보입니다.

JSON

{ "prop": "feather", "keys": [{ "t": 0, "v": 0.3 }] }

참고

보통 키프레임 하나로 고정해 씁니다. 셰이더 마스크라 한 화면에 많이 쓰면 저사양 단말에서 프레임이 떨어질 수 있습니다.

이 페이지의 움직임은 CSS 근사입니다. 곡선 값은 keyframe_motion 엔진과 조금 다를 수 있습니다. 엔진과 같은 값으로 재생하는 데모는 design/motion-demo 입니다.
